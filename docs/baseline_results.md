# Baseline reproduction results


## Setup

- Test split: 550 rows, 4 held-out genes (CUL3, HPRT1, NF2, TADA1)
- Feature count: 610 sequence + 2 biological context
- Hyperparameters: see `XGB_PARAMS` in `ml/scripts/train_baseline.py`

## Metrics

All CIs are bootstrap (n=1000) 95% intervals.

| Metric | Reproduction | Azimuth V3 on same rows | Paper (Doench 2016) |
|---|---|---|---|
| Spearman rho | **+0.459 [+0.389, +0.527]** | +0.665 | ~0.55 |
| Pearson r | **+0.471 [+0.404, +0.531]** | +0.678 | — |
| AUC (>median) | **+0.670 [+0.616, +0.719]** | +0.783 | — |

## Reproduction sanity check

How tightly our predictions track Azimuth V3 on the same test set
(closer to 1.0 means we are replicating Rule Set 2 rather than
fitting to noise):

- Spearman (ours vs. Azimuth): +0.825
- Pearson  (ours vs. Azimuth): +0.818

## Commentary

The training corpus is small (5,310 rows across 17 genes) and we
evaluate leave-genes-out (4 held-out genes), which is harder than
within-gene cross-validation. Doench 2016 reports Spearman rho
~0.55 on held-out genes; the relevant comparison is between our
number and that paper number, not between our number and Azimuth's
predictions on this same test set. Azimuth's `predictions` column
is generated by the V3 model which was trained on a different
cross-validation fold, so its apparent advantage on this test set
is partly information leakage and not a fair head-to-head.

Where our number diverges from paper:
- Split protocol: paper uses leave-one-gene-out CV across all 17
  genes; we use a single 9/4/4 partition by row balance.
- Feature scope: Rule Set 2 includes secondary-structure features
  computed with `viennarna`, deferred due to Windows install pain.
